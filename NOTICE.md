# Research status notice

This repository is an exploratory mathematical/computational research record. It does **not** contain a proof of global regularity or finite-time blowup for the three-dimensional incompressible Navier–Stokes equations.

Results labeled as model theorems, asymptotics, numerical observations, or conditional statements retain those qualifications. The repository intentionally preserves failed routes, retractions, and corrected diagnostics so that later readers can audit how the conclusions changed.
